# Agent Note: 新手指引

Status: implemented

## Problem

新玩家第一次打开时只有零散的提示（第一次开战的浮动提示、准备面板里的说明文字、战斗底栏的操作提示），没有完整的指引；跳过或忘了之后也没有地方重看。需要确定指引的形式、弹出时机、重看入口和内容范围。

## Proposal

- 形式：跟着第一场走的分步高亮，在真实界面上逐步圈出要点，每步一句话，边看边操作，随时可以跳过。理由：用户 2026-09-27 选定；Brief §6 要求教学尽量发生在第一次真实选择与行动中。
- 时机：新安装后，进入第一场战前准备时自动开始，战斗部分在第一次开战时接着讲；标题页不弹。理由：用户 2026-09-27 选定；Brief §6 要求首次打开不先经历多个弹窗。已取代 → [新手指引改成游戏式教学](2026-09-27-game-style-tutorial.md)
- 跳过：一次跳过整个指引，之后不再自动出现。理由：用户 2026-09-27 要求可以跳过。
- 重看：标题页和游戏顶栏常驻“？”按钮，点一下立即重看；战斗中打开会自动暂停。理由：用户 2026-09-27 要求跳过后仍能再次查看，并选定此方式。
- 内容：基本操作（本场目标、开局招式、站位、开战、暂停、放招式、集火）加一轮的规则（回响怎么叠、赢了挑奖励与槽位、输了怎么重试），每步一句话，约 8–10 步。理由：用户 2026-09-27 选定。已取代 → [新手指引改成游戏式教学](2026-09-27-game-style-tutorial.md)

## Decision

与 Proposal 一致，按下方 Plan 落实。

## Plan

以下是 v0.2.0 的做法。用户 2026-09-27 试用后要求重做，当前实现见 [新手指引改成游戏式教学](2026-09-27-game-style-tutorial.md)。

- 三段共 10 步：准备（本场目标、开局招式、队伍配置、站位、开战）、战斗（暂停、主动招式、集火、回响）、第一场结算（胜负之后怎么办）。“开局招式”一步只在还能改选开局招式时出现。
- 表现：半透明遮罩挖出目标区域并描边，旁边放一句话卡片（进度点、跳过、上一步、下一步），卡片依次试下、上、右、左，找不压住目标的位置；侧栏里被滚走的目标先滚进视野。被圈出的元素可以直接点，在“开战”一步直接点开战会接着讲战斗。键盘 → / Enter 下一步，← 上一步，Esc 跳过；指引打开时其它游戏按键不生效（M 静音除外）。
- 游戏内“？”重看当前界面对应的一段（奖励界面讲挑奖励，整轮结算界面翻看全部）；标题页没有可圈的界面，按顺序翻看全部步骤的文字卡片。重看不改变进度，左下角按钮是“关闭”。
- 新安装判定：存档记录各段是否看过。存档格式升到版本 2，读入旧版存档时视为已看过；“清除全部存档”后恢复为新安装。
- 第一次开战时的浮动提示并入指引，不再单独出现。

## Acceptance criteria

- 新安装后进入第一场准备阶段自动出现指引；跳过后重启不再自动出现；各界面的“？”都能重看。
- 战斗部分出现时战斗暂停，关闭后继续。
- 960×600 至 1920×1080 窗口下，卡片不遮住被圈出的元素、不溢出。
- 旧版本存档读入后不自动出现指引。

## Verification

- 端到端测试覆盖：新安装后准备、战斗、结算三段依次出现，讲战斗时计时停住、关闭后继续；看完或跳过后重启不再自动出现；“？”在准备和战斗中重看（战斗中暂停），标题页翻看全部；写入 v0.1.0 格式的存档后启动不弹出。CI 在打包好的 macOS、Windows 程序上跑同一套测试。
- 单元测试覆盖存档里的指引进度：新存档为空、往返保留、旧版本存档视为看过、非法值被过滤。
- 在 960×600 与 1280×800 窗口逐步截图检查，10 步的卡片都没有压住被圈出的元素，也没有溢出。
- 未验证：真实触控板上的操作手感，以及 Mac、Windows 真机上的显示。
