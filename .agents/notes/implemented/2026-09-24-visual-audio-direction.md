# Agent Note: 视觉与声音方向

Status: implemented

## Problem

第一版就要“看起来和动起来有意思”，表现同时要服务于读懂局面，且不能依赖在线素材。需要确定二维风格、敌我与状态的表达方式、连锁反馈和声音方案。

## Proposal

- 采用有辨识度、轻松而不敷衍的二维表达；避免工业控制台、赛博监控大屏、代码终端、整页企业仪表盘或通用后台模板。理由：Brief §6、§7。
- 竞技场是视觉中心；重要事件（谁发动、作用于谁、产生了什么变化）由位置、动作、轨迹、声音和必要提示共同表达；视觉强度可随连锁增大，但敌我与关键状态要始终看得清。理由：Brief §6、§7。
- 选中、装配、启动、碰撞、反射、连锁、胜负等关键时刻有适量且一致的反馈；音效可以程序化，运行时不依赖在线素材、外部字体或流媒体；处理好首次音频启用、静音和后台暂停。理由：Brief §7。
- 默认使用简体中文，常见笔记本窗口下可读；关键内容不依赖悬停；不只靠红绿区分状态；音量、静音、暂停容易找到；明显的动效和闪烁要克制。理由：Brief §6。
- 美术方向由 Agent 决定。理由：Brief §3、§7 与用户 2026-09-24 授权。

## Decision

与 Proposal 一致，按下方 Plan 落实。

## Plan

- 题材是深夜书桌上的“桌面玩具联赛”：毛毡棋盘加木框当竞技场，玩具队员和对手站在棋子底座上，全部用程序化矢量图形绘制，不带图片素材。
- 造型按“有体积的玩具”画（2026-09-30 用户要求优化角色和对手的建模）：台灯主光在左上，每个部件叠体积渐变、背光边缘反光、高光和描边；铁皮、黄铜、塑料、毛绒、镜面等材质各有画法；台灯投下的软影子随位置变化。动作成套：走路弹跳、蓄力下蹲、出手前冲、受击后仰（加短暂闪白）、冲锋拉伸留残影、出场落地、倒下翻倒淡出，另有眨眼、表情（生气、专注、受击、晕眩）和发条转动。
- 敌我同时用颜色（暖黄、天青 / 梅紫、珊瑚）、背光边缘的队伍色反光、底座形状和血条样式区分，不只靠红绿；我方残血时底座内圈变红。
- 回响等级用颜色梯度加五声音阶逐级升高的音符表达；1 级只画光圈，2 级起标注等级，附近的标注合并；特效随等级升级（3 级起地面光照与电光，4 级起冲击波，5 级起放射光芒）；大连锁配适度震屏，震屏可关闭。
- 特效（2026-09-30 用户要求“炫酷的特效”）：低分辨率泛光层、地面光照、焦痕与裂纹、沿真实飞行路线的弹道拖尾、卡通火球与烟、弹射闪电、冲击波、刀光、漩涡粒子、胜利彩纸，全部用 Canvas 2D 程序生成。
- 克制与可读（对应 Proposal “明显的动效和闪烁要克制”与“敌我与关键状态要始终看得清”）：没有全屏闪光，首领换阶段用压暗；同一处 0.08 秒内只闪一次；泛光层内用普通叠加，大量特效叠在一起也不会白成一片；血条和数字画在特效之上；持续的明暗脉动（引信、残血、加时）不快于每秒 3 次。“减少闪烁”去掉受击闪白、闪电折线的抖动和放射光芒，地面光照与泛光减弱，脉动改为常亮。
- 性能：粒子、光源、焦痕、文字等各有上限；按实际帧间隔自动降画质（减少粒子，更低时关掉泛光），流畅后再恢复。
- 伤害与治疗数字：同一单位 0.3 秒内的连续数值合并成一个，附近数字自动错开，激烈场面不刷屏；可在设置中关闭。
- 声音全部由 Web Audio 程序化合成，不带音频文件，首次点击后启用。
- 界面是游戏风格的 DOM 叠加层（厚按钮、纸板面板），用系统中文字体栈。

## Acceptance criteria

- 在 1280×720 及更小的常见笔记本窗口截图中无遮挡、溢出，文字可读。
- 激烈场面截图中敌我、血量与回响仍可辨认；设置中可关闭震屏并调节音量。

## Verification

- 在 960×600（最小窗口）、1024×640、1280×720、1280×800、1440×900、1920×1080 窗口截图检查标题、准备和战斗界面，无遮挡或溢出（最窄时战斗底栏收起操作提示栏）；结算、奖励与整轮结算在 1280×800 下检查。
- 爆爆虫连环爆炸、镜甲骑士、发条大王等激烈场面截图中，合并伤害数字后仍能分辨敌我、血量与回响。
- 声音未实际试听（开发环境没有音频输出），只确认运行时音频模块无报错；高分辨率（Retina）屏幕与真实触控板未检查。
- 2026-09-30 造型与特效升级：13 种单位在待机、走路、蓄力、出手、受击、倒下各状态的造型图，以及各类特效按时间展开的样张（含“减少闪烁”）逐一检查；爆爆虫潮连爆、三个主动招式同时放、首领暴走等场面的截图（1 倍与 2 倍缩放）中，敌我、血量与回响仍可辨认。初版在爆炸与漩涡爆发处会白成一片挡住单位，加入闪光节流并把泛光层改为普通叠加后解决。
- 帧率只在 Linux 无显卡（软件渲染）环境测过：1280×800 窗口的爆爆虫潮全程平均每帧约 17.5–18 毫秒（上一版约 16.8 毫秒），关掉泛光时与上一版持平；有显卡的 Mac / Windows 真机上的观感与帧率未测。
