# Agent Note: 视觉与声音方向

Status: implemented

## Problem

第一版就要“看起来和动起来有意思”，表现同时要服务于读懂局面，且不能依赖在线素材。需要确定二维风格、敌我与状态的表达方式、连锁反馈和声音方案。

## Proposal

- 采用有辨识度、轻松而不敷衍的二维表达；避免工业控制台、赛博监控大屏、代码终端、整页企业仪表盘或通用后台模板。理由：Brief §6、§7。已取代 → [三维宠物军团改版](2026-09-30-3d-pet-legion.md)
- 竞技场是视觉中心；重要事件（谁发动、作用于谁、产生了什么变化）由位置、动作、轨迹、声音和必要提示共同表达；视觉强度可随连锁增大，但敌我与关键状态要始终看得清。理由：Brief §6、§7。
- 选中、装配、启动、碰撞、反射、连锁、胜负等关键时刻有适量且一致的反馈；音效可以程序化，运行时不依赖在线素材、外部字体或流媒体；处理好首次音频启用、静音和后台暂停。理由：Brief §7。
- 默认使用简体中文，常见笔记本窗口下可读；关键内容不依赖悬停；不只靠红绿区分状态；音量、静音、暂停容易找到；明显的动效和闪烁要克制。理由：Brief §6。
- 美术方向由 Agent 决定。理由：Brief §3、§7 与用户 2026-09-24 授权。

## Decision

与 Proposal 一致，按下方 Plan 落实。其中“二维表达”一条自 2026-10-01 起由 [三维宠物军团改版](2026-09-30-3d-pet-legion.md) 取代，画面改为三维卡通渲染；其余各条照旧适用。

## Plan

三维的造型、特效、镜头与战场见 [三维宠物军团改版](2026-09-30-3d-pet-legion.md)。这里记录读懂局面与克制的做法：

- 敌我：脚下光圈与血条按队伍分色（我方天青、对手珊瑚），不只靠红绿；血条旁标属性与星级；集火目标套着旋转的四角框。
- 回响：等级用颜色与五声音阶逐级升高的音符表达，上限 8 级；第一次打出 2 级以上回响时新手指引停下来讲。
- 特写：技能特写约 3 秒一次，我方大招 6 秒、对手大招 11 秒，没轮上的只给短暂慢动作；可在设置里关闭。特写时血条与数字变淡但不消失，挡在镜头前的单位暂时隐去，泛光收一些。
- 克制：全屏闪白只在分出胜负时出现一次；“减少闪烁”去掉闪白和色差，光效减弱；震屏可关闭。
- 伤害与治疗数字：同一处 0.25 秒内的数字合并成一个，可在设置里关闭。
- 性能：粒子、特效、碎块各有上限；四档画质按实际帧率自动升降，设置里可以固定。
- 声音：Web Audio 程序化合成，不带音频文件，首次点击后启用；窗口失焦时挂起；同时发声的数量有上限，同类声音在同一批事件里合并。
- 界面：深色半透明面板的 DOM 叠加层，系统中文字体栈；展示台上的宠物围绕正面左右摆动，不转到背面。

## Acceptance criteria

- 在 1280×720 及更小的常见笔记本窗口截图中无遮挡、溢出，文字可读。
- 激烈场面截图中敌我、血量与回响仍可辨认；设置中可关闭震屏并调节音量。

## Verification

- 2026-09-30 三维版：在 960×600、1280×800 窗口逐屏截图检查标题、选伙伴、战前（含指引）、战斗、结算、奖励、进化演出、图鉴与设置，无遮挡或溢出（窄窗口下奖励的收服与进化两行仍左右并排）；另在 1280×800 检查技能特写、大招镜头与十只人形态对首领的激烈场面，敌我、血量与回响仍可辨认。
- 大招镜头初版会被别的单位挡住（镜头钻进烛龙身体里），改为从候选机位里挑视线最清楚的、并隐去挡在前面的单位；特写时血条初版完全隐去，改为变淡。
- 帧率只在 Linux 无显卡（软件渲染）环境测过：画质自动降到最低档，十只人形态对首领、镜头推近大体型单位时明显掉帧；有显卡的 Mac / Windows 真机上的观感与帧率未测。
- 声音未实际试听（开发环境没有音频输出），只确认运行时音频模块无报错，并用离线渲染核对过音量峰值与同时发声上限。高分辨率（Retina）屏幕与真实触控板未检查。
