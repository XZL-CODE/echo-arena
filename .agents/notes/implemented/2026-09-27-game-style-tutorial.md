# Agent Note: 新手指引改成游戏式教学

Status: implemented

## Problem

v0.2.0 的新手指引是“圈出一个界面元素 + 一句文字”，更像网页产品的功能导览；标题页的“新手指引”没有界面可圈，只是按顺序翻十张纯文字卡片。用户 2026-09-27 试用后指出：游戏的新手指引应当有具体画面和动画，聚焦到位置，讲清第一步做什么、第二步做什么，并要求参考别的游戏的做法。

游戏里常见的新手引导有几条共同做法：压暗其余界面，只亮出要操作的地方；用手指或箭头动画演示点哪里、往哪拖；玩家照着做了才往下走，期间游戏停着等；机制在第一次真的发生时停下来讲；主菜单里可以重玩教学关。

原 Note [新手指引](2026-09-27-onboarding-guide.md) 的 Proposal 要求战斗部分在第一次开战时讲完、全程约 8–10 步；按下面的做法，放招式要等玩家第一次有主动招式时才教，合计 11 步。

## Proposal

- 演示：每一步压暗其余界面、亮出要操作的地方，用手指动画演示点哪里、往哪拖，卡片上提示对应按键；亮出来的地方以外点不到。理由：用户 2026-09-27 要求有画面动画、聚焦到位置。
- 照做推进：第一次教时，要操作的步骤得照着做了才进入下一步，讲战斗时战斗停着等；只需要看的步骤点“知道了”；“跳过指引”始终可用，一次跳过全部。理由：用户要求讲清第一步做什么、第二步做什么；照着做一遍比读说明记得住。
- 按情形教：分六课，各在对应情形第一次出现时教——第一次战前准备（看对手、选开局招式、拖动队员、开战）、第一次开战（点对手集火、按空格开打）、第一次能放主动招式（先点招式按钮，再点场地）、第一次打出回响（定格在那一刻，画出弹丸接下来飞向谁）、第一场结算、第一次挑奖励。每步一句话，合计 11 步。理由：默认开局招式反射盾是被动的，放招式只能等玩家第一次有主动招式时照着做；回响在真的发生时讲最直观。已取代 → [三维宠物军团改版](2026-09-30-3d-pet-legion.md)
- 教学战：标题页的“新手指引”进入一场教学战，从头教一遍全部课程；打完回到标题或开始正式一轮，不读写存档里的这一轮。理由：标题页没有可操作的界面，纯文字卡片没有画面；从菜单重玩教学关是游戏常见的重看方式。
- 游戏里的“？”：重看当前界面的课，每一步都能直接点“下一步”翻，不要求照做，也不改变学习进度。理由：重看是为了查操作，不必再逼玩家做一遍。

## Decision

用户 2026-09-27 确认本 Proposal，取代 [新手指引](2026-09-27-onboarding-guide.md) Proposal 中“时机”“内容”两条；实现与 Proposal 一致，按下方 Plan 落实。2026-10-01 起玩法改为宠物军团，“按情形教”一条由 [三维宠物军团改版](2026-09-30-3d-pet-legion.md) 取代，课程随之调整；演示、照做推进、教学战与“？”重看照旧。

## Plan

- 画面：SVG 遮罩挖出一个或几个圆角区域并描边，可以亮出界面元素，也可以亮出 3D 战场里一方的单位。白手套手指循环演示“移过来、按下、荡开一圈”；拖动时沿虚线箭头把宠物拖到虚线圈；回响课圈出回响发生的位置。指尖离窗口底边太近时，手指倒过来从上方指。说明卡片带九焰头像和指向目标的小三角，摆放时依次避开亮出来的地方、手指和要留着看的地方；窗口矮时卡片收紧。
- 课程（六课十二步）：战前准备（看对手、认识军团、拖动一只宠物摆站位、开战）、开战（点一个敌人集火、暂停与加速）、回响、大招、结算、挑奖励（收服、进化、确认）。拖动演示拿我方最前面的一只，往场地中线方向挪一大步；摆站位时镜头不动，拖到哪里只取决于指针。
- 输入：指引打开时，亮出来的地方以外的点击在捕获阶段拦下；键盘只放行这一步提示的按键（开战与确认的 Enter），Esc 跳过，Enter、→、空格翻过只需要看的步骤。
- 课程触发：战前准备与开战在进入对应界面时；回响在第一次出现 2 级以上回响时，当帧停住战斗；大招在我方第一次放大招时；结算、挑奖励在进入对应界面时。界面切走时正在教的课算学过。
- 进度：存档格式版本 4 按课记录（prep、battle、echo、ult、result、reward）。版本 4 以前的存档来自旧玩法，学习进度清空、重新教（见 [三维宠物军团改版](2026-09-30-3d-pet-legion.md)）。“清除全部存档”后恢复为新安装。
- 教学战：只在内存里的一轮，固定种子、轻松难度的第一场森林新芽队，伙伴是人形态九焰（能教到大招）。不管存档里学没学过，每课都从头教一次；打赢后挑奖励，然后回到标题，说明学会了什么，按钮是“开始正式一轮”（有进行中的一轮时是“继续我的这一轮”）和“回到标题”。教学战里学过的课也记进存档。
- “？”：战前、结算、奖励界面的右上角和战斗 HUD 的右上角常驻，重看当前界面的课；标题页的“新手指引”进教学战。

## Acceptance criteria

- 新安装后按情形依次教，要操作的步骤照着做才往下走；跳过后不再自动出现；各界面的“？”能重看。
- 标题页的“新手指引”进入教学战并走完全部课程，存档里的这一轮不变。
- 960×600 至 1920×1080 窗口下，卡片不压住要点的地方，手指不出窗口。
- v0.4.0 及以前（旧玩法）的存档升级后重新教（2026-10-01 起，见 [三维宠物军团改版](2026-09-30-3d-pet-legion.md)；此前的要求是 v0.1.0、v0.2.0 的存档更新后不自动教）。

## Verification

- 端到端测试（2026-09-30 宠物军团版）：新安装依次走完战前、开战、回响、结算、挑奖励（第一场打输时改走回到战前），并核对要操作的步骤没有“下一步”、亮出来的地方以外点不到、讲解时战斗停住、学完重启不再出现；跳过后开战、回响、结算、奖励都不再出现；教学战里依次教到回响与大招，打完挑奖励后回到标题，存档里的这一轮不变；“？”在战前和战斗中重看（战斗中暂停），不改变学习进度；旧玩法的存档升级后重新教。CI 在打包好的 macOS、Windows 程序上跑同一套测试。
- 单元测试：存档里学习进度的版本处理；教学战的配置（固定种子、轻松难度、第一场、伙伴是人形态）。
- 在 960×600、1280×800 窗口逐步截图检查：卡片不压住要点的地方，手指在窗口内。
- 2026-09-30 CI 上新安装这一课的第一场时胜时负：战前镜头的缓慢漂移让同样的拖动落到不同位置，站位随之不同。改为摆站位时镜头不动后解决，测试也兼顾了打输的走向。
- 未验证：真实触控板上的手感，Mac、Windows 真机上的显示。
