# Agent Note: 核心玩法：短局战术竞技场与回响连锁

Status: implemented

## Problem

Brief 给出了体验目标（目标清楚、尝试轻松、办法有分量、结果看得见）和建议起点，但核心操作方式、局内成长、失败规则和一轮的结构需要确定，让“看懂局面 → 产生想法 → 快速配置或行动 → 看见效果 → 调整或推进 → 完整结束”尽早成立。

## Proposal

- 以短局、能力组合、明确对手、可见连锁反馈为起点，做小规模战术竞技场，只选一套清楚的核心操作方式。理由：Brief §3、§5。
- 普通移动与攻击不需要高频输入，关键决策属于玩家；如果自动战斗，站位与配置要实际影响过程，可加入次数或时机有限的主动干预；战斗可暂停，适合触控板，不依赖精密瞄准和高反应速度。理由：Brief §2、§5。
- 能力少而有辨识度，优先改变行为、攻击路径、站位、触发条件和节奏，数值升级只作辅助；用槽位、候选等形成取舍，不开局全拿，能力在一轮内逐步获得。理由：Brief §5。
- 不用跨局刷材料、签到、限时任务或永久战力累积制造留存；长期保存限于记录类内容。理由：Brief §3、§5。
- 失败后能回到战前调整再试，不抹掉大量进度；同一场重试的条件可比较。理由：Brief §5。
- 一轮约二十至三十分钟，结束有完整结算，不自动开启下一轮。理由：Brief §5、§6。
- 反馈来自实际战斗记录，不编造分析，不接入大模型。理由：Brief §5。
- 不做联网对战、账号、商业化、每日任务、长剧情、开放地图、复杂采集制作、长期数值养成和运行时大模型调用。理由：Brief §8。
- 题材、机制、数值和关卡由 Agent 决定并记录。理由：Brief §3 与用户 2026-09-24 授权。

## Decision

与 Proposal 一致，按下方 Plan 落实。一轮时长按自动对战估计约 15–25 分钟（每场战斗约 15–80 秒），与“约二十至三十分钟”大体相符，尚未经真人计时。

## Plan

- 三名玩具队员（阿铁、小弹、叮当）自动移动和攻击。玩家负责开局招式、装配、站位，战斗中每人最多一个带冷却的主动招式，并可点敌人集火。空格随时暂停，暂停时也能下达干预；可切换 2 倍速。
- 用“回响”统一连锁规则：反射、弹射、撞墙反弹、撞击、连爆、镜桩折返、弹簧弹开每传递一次，回响 +1。伤害随等级递增并有上限，颜色和音高随之上升，方便看懂因果；反射次数、弹丸和单位数量都有上限，避免无限触发与卡顿。
- 一轮 7 场：第 1 场固定为木箭齐射队（对应 Brief 示例），中间 5 场按层级从对手池抽取，第 7 场是首领发条大王。对手之间主要靠阵形、攻击方式、互相支援和地形区分，后面的场次另有小幅属性成长。胜利后三选一（新招式或进阶），每名队员 2 个槽位，主动招式每人最多 1 个；14 个招式分折返、弹跳、冲撞、聚拢、守护五类思路。
- 开局招式三选一（反射盾 / 冲锋 / 厚甲），默认反射盾，第一场开战前可换。
- 失败后可原样再来，或回到战前调整，配置与站位保留。同一场使用固定种子，每个单位有独立随机流。60 秒后进入加时，双方伤害逐步提高；180 秒仍未分出胜负判负，避免僵局。
- 结算只展示战斗中实际记录的数据。难度（轻松 / 标准 / 硬核）只影响新开的一轮。

## Acceptance criteria

- 默认配置可直接开战；第一场就能看见一次可理解的能力效果。
- 至少两种不同思路能通过每一场；组合确实改变战斗过程（有可重复的场景测试）。
- 胜负、重试、奖励选择、整轮结算全流程可玩，连锁不会无限触发或拖垮帧率。

## Verification

- 规则测试覆盖各招式的触发条件与效果、回响加伤与反射乒乓上限、同种子战斗可完全复现、每场在时限内结束，以及一轮的场次安排、装配、奖励与结算提示。
- 自动对战脚本（按固定规则放招式，不集火、不调站位）显示每一场至少有两种不同思路的配置能赢；它比真人弱，真人实际难度待试玩确认。
- 客户端端到端测试走通开局、战斗、胜利选奖励、失败后原样再来与回去调整、最后一场后的整轮结算与再来一轮。
- 待确认：是否好玩、真人一轮的实际时长与难度，需要用户试玩判断。
