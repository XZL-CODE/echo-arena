# Agent Note: 核心玩法：短局战术竞技场与回响连锁

Status: implemented

## Problem

Brief 给出了体验目标（目标清楚、尝试轻松、办法有分量、结果看得见）和建议起点，但核心操作方式、局内成长、失败规则和一轮的结构需要确定，让“看懂局面 → 产生想法 → 快速配置或行动 → 看见效果 → 调整或推进 → 完整结束”尽早成立。

## Proposal

- 以短局、能力组合、明确对手、可见连锁反馈为起点，做小规模战术竞技场，只选一套清楚的核心操作方式。理由：Brief §3、§5。
- 普通移动与攻击不需要高频输入，关键决策属于玩家；如果自动战斗，站位与配置要实际影响过程，可加入次数或时机有限的主动干预；战斗可暂停，适合触控板，不依赖精密瞄准和高反应速度。理由：Brief §2、§5。
- 能力少而有辨识度，优先改变行为、攻击路径、站位、触发条件和节奏，数值升级只作辅助；用槽位、候选等形成取舍，不开局全拿，能力在一轮内逐步获得。理由：Brief §5。
- 不用跨局刷材料、签到、限时任务或永久战力累积制造留存；长期保存限于记录类内容。理由：Brief §3、§5。
- 失败后能回到战前调整再试，不抹掉大量进度；同一场重试的条件可比较。理由：Brief §5。
- 一轮约二十至三十分钟，结束有完整结算，不自动开启下一轮。理由：Brief §5、§6。
- 反馈来自实际战斗记录，不编造分析，不接入大模型。理由：Brief §5。
- 不做联网对战、账号、商业化、每日任务、长剧情、开放地图、复杂采集制作、长期数值养成和运行时大模型调用。理由：Brief §8。
- 题材、机制、数值和关卡由 Agent 决定并记录。理由：Brief §3 与用户 2026-09-24 授权。

## Decision

与 Proposal 一致，按下方 Plan 落实。2026-09-30 用户要求整体改版，玩法改为宠物军团自动对战（决定与边界见 [三维宠物军团改版](2026-09-30-3d-pet-legion.md)），仍在本 Proposal 的范围内：开放的是战场视野，不是可探索的开放地图。一轮时长按自动对战估计约 15–20 分钟（每场战斗约 40–80 秒，加上战前与挑奖励），略短于“约二十至三十分钟”，尚未经真人计时。

## Plan

- 军团：开局 4 只幼年同伴（一只坦克、一只辅助、两只输出）加三选一的伙伴（开局就是进化形态）；每场可上场的宠物数依次为 5、6、7、8、9、10、10。宠物按定位自己走位与出招：坦克挡在前面，刺客扑向残血，远程隔着距离输出，辅助回血、加护盾；普通攻击收招后接步法（后撤、侧移、绕身、交叉换位），随机但同一场可复现。
- 玩家的决定：带谁上场、战前拖动站位（限制在我方布阵区）、战斗中点敌人设集火（再点一次取消）。空格暂停，1 / 2 / 3 倍速。
- 五系相克：水克火、火克木、木克岩、岩克雷、雷克水；克制时伤害 ×1.3，被克制 ×0.85。战前列出对手的宠物、属性和克制它们的属性。
- 形态：幼年、进化形态、人形态，形态越高属性越高、技能越强；只有人形态有能量，从 30 开始攒，满 100 自动放大招。
- 回响：被技能击飞的单位撞上别的单位或场地边缘、弹丸被反射或弹射时回响 +1；每级伤害 +25%，上限 8 级。反射次数、弹丸、单位、区域数量都有上限，不会无限触发。
- 一轮 7 场：前 6 场按档位从对手池抽取，各有主题属性与阵容；第 7 场是首领烛龙，生命降到一半化为人形的烛龙君，并不时召唤幼年宠物助战。胜利后收服（候选里选一只，军团满了没有）与进化（候选里选一只）各选一项，同时生效；第二次奖励起候选里一定有能进化到人形态的。
- 失败后可原样再来或回到战前调整，军团与站位保留；同一场使用固定种子。60 秒后进入加时，每 10 秒伤害提高一档；180 秒仍未分出胜负判负。
- 结算只展示战斗中实际记录的数据（伤害占比、克制、回响、MVP）；整轮结算列出扛起这一轮的宠物和最有用的招式。图鉴记录见过或拥有过的形态，不带跨局战力。难度（轻松 / 标准 / 硬核）只影响新开的一轮。

## Acceptance criteria

- 默认配置可直接开战；第一场就能看见一次可理解的能力效果。
- 至少两种不同思路能通过每一场；组合确实改变战斗过程（有可重复的场景测试）。
- 胜负、重试、奖励选择、整轮结算全流程可玩，连锁不会无限触发或拖垮帧率。

## Verification

- 规则测试 63 项覆盖相克与伤害、各技能与大招、回响加伤与上限、步法、首领变身与召唤、集火、加时与时限、同种子战斗完全复现、每场在时限内结束，以及一轮的场次与军团上限、伙伴改选、奖励、重试、布阵、教学战配置、图鉴与结算提示。
- 自动对战报告（四种挑奖励策略、每种 24 个种子，不集火、不调站位）：标准难度每场 40–80 秒，“先进化”“伙伴带队”两种思路每一场第一次尝试的胜率都在 63% 以上，“先收服”“混合”在后几场明显吃力；轻松难度四种策略都能打通；它比真人弱，真人实际难度待试玩确认。
- 客户端端到端测试走通开局、胜利后收服与进化、失败后原样再来与回去调整、最后一场后的整轮结算。
- 待确认：是否好玩、真人一轮的实际时长与难度，需要用户试玩判断。
