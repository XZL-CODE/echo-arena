# Agent Note: 新手指引改成游戏式教学

Status: proposed

## Problem

v0.2.0 的新手指引是“圈出一个界面元素 + 一句文字”，更像网页产品的功能导览；标题页的“新手指引”没有界面可圈，只是按顺序翻十张纯文字卡片。用户 2026-09-27 试用后指出：游戏的新手指引应当有具体画面和动画，聚焦到位置，讲清第一步做什么、第二步做什么，并要求参考别的游戏的做法。

游戏里常见的新手引导有几条共同做法：压暗其余界面，只亮出要操作的地方；用手指或箭头动画演示点哪里、往哪拖；玩家照着做了才往下走，期间游戏停着等；机制在第一次真的发生时停下来讲；主菜单里可以重玩教学关。

原 Note [新手指引](../implemented/2026-09-27-onboarding-guide.md) 的 Proposal 要求战斗部分在第一次开战时讲完、全程约 8–10 步；按下面的做法，放招式要等玩家第一次有主动招式时才教，合计 11 步，因此那两条标为待裁定。

## Proposal

- 演示：每一步压暗其余界面、亮出要操作的地方，用手指动画演示点哪里、往哪拖，卡片上提示对应按键；亮出来的地方以外点不到。理由：用户 2026-09-27 要求有画面动画、聚焦到位置。
- 照做推进：第一次教时，要操作的步骤得照着做了才进入下一步，讲战斗时战斗停着等；只需要看的步骤点“知道了”；“跳过指引”始终可用，一次跳过全部。理由：用户要求讲清第一步做什么、第二步做什么；照着做一遍比读说明记得住。
- 按情形教：分六课，各在对应情形第一次出现时教——第一次战前准备（看对手、选开局招式、拖动队员、开战）、第一次开战（点对手集火、按空格开打）、第一次能放主动招式（先点招式按钮，再点场地）、第一次打出回响（定格在那一刻，画出弹丸接下来飞向谁）、第一场结算、第一次挑奖励。每步一句话，合计 11 步。理由：默认开局招式反射盾是被动的，放招式只能等玩家第一次有主动招式时照着做；回响在真的发生时讲最直观。
- 教学战：标题页的“新手指引”进入一场教学战，从头教一遍全部课程；打完回到标题或开始正式一轮，不读写存档里的这一轮。理由：标题页没有可操作的界面，纯文字卡片没有画面；从菜单重玩教学关是游戏常见的重看方式。
- 游戏里的“？”：重看当前界面的课，每一步都能直接点“下一步”翻，不要求照做，也不改变学习进度。理由：重看是为了查操作，不必再逼玩家做一遍。

## Plan

- 画面：SVG 遮罩挖出一个或几个圆角区域并描边。白手套手指循环演示“移过来、按下、荡开一圈”；拖动时沿虚线箭头把队员拖到虚线圈；回响课不画手指，一个亮点沿虚线飞向弹丸的去向。指尖离窗口底边太近时，手指倒过来从上方指。说明卡片带叮当头像和指向目标的小三角，摆放时依次避开亮出来的地方、手指、要留着看的地方（如结算战报，只轻微压暗）；窗口矮时卡片收紧。
- 输入：指引打开时，亮出来的地方以外的点击在捕获阶段拦下；键盘只放行这一步提示的按键（开战的 Enter、开打的空格、放招式的数字键、挑奖励的 1/2/3 与 Enter），Esc 跳过，Enter、→、空格翻过只需要看的步骤。
- 课程触发：战前准备与开战在进入对应界面时；放招式在战斗进行 2 秒后、上一课结束 1.5 秒后第一次有主动招式可用时（玩家已经自己放过就算学过）；回响在第一次出现我方回响事件时，当帧停住战斗；结算、挑奖励在进入对应界面时。界面切走时正在教的课算学过。
- 进度：存档格式升到版本 3，按课记录（prep、battle、skill、echo、result、reward）。版本 1 的存档视为全部学过；版本 2 看过“战斗”的算学过放招式和回响，看过“结算”的算学过挑奖励。“清除全部存档”后恢复为新安装。
- 教学战：只在内存里的一轮，固定种子、轻松难度的第一场木箭齐射队，叮当额外带主动招式漩涡（换开局招式时保留）。顶栏标“教学战 · 不影响存档”，菜单里是“结束教学战，回到标题”；挑完奖励显示学会了什么，按钮是“开始正式一轮”（有进行中的一轮时是“继续我的这一轮”）和“回到标题”。教学战里学过的课也记进存档，之后正式开一轮不再重复教。

## Acceptance criteria

- 新安装后按情形依次教，要操作的步骤照着做才往下走；跳过后不再自动出现；各界面的“？”能重看。
- 标题页的“新手指引”进入教学战并走完全部课程，存档里的这一轮不变。
- 960×600 至 1920×1080 窗口下，卡片不压住要点的地方，手指不出窗口。
- v0.1.0、v0.2.0 的存档更新后不自动教。

## Verification

- 端到端测试：新安装依次走完战前、开战、回响、结算、挑奖励，并核对要操作的步骤没有“下一步”、亮出来的地方以外点不到、讲解时计时停住、学完重启不再出现；跳过后开战、回响、结算都不再出现；教学战里放招式两步照着做，打完回到标题，存档里的这一轮不变；“？”在准备和战斗中重看（战斗中暂停），不改变学习进度；v0.1.0、v0.2.0 格式的存档不自动教。
- 单元测试：存档里学习进度的版本换算与非法值过滤；教学战的配置，以及换开局招式时保留漩涡。
- 在 960×600、1280×800、1440×900、1920×1080 窗口逐步截图检查：卡片不压住要点的地方，底部按钮上的手指倒过来后仍在窗口内。
- 未验证：真实触控板上的手感，Mac、Windows 真机上的显示。
