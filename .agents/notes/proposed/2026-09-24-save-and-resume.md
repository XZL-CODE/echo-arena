# Agent Note: 暂停、存档与恢复

Status: proposed

## Problem

这是随时打开、随时可能被打断的本地游戏。需要确定保存哪些内容、何时保存、存到哪里、关闭后如何继续，以及怎样安全重置。

## Proposal

- 提供明确的暂停、继续和新开一轮入口，不用创建账号来解决保存。理由：Brief §5。
- 至少保存当前进程、已做出的局内选择、战前检查点和基础设置；可以只恢复到战前状态，但不能丢掉重要决定，并要让玩家清楚从哪里继续。理由：Brief §5。
- 可能覆盖当前进度的操作要有清楚提示。理由：Brief §5。
- 窗口失焦或系统打断时，不继续制造难以察觉的损失。理由：Brief §6。
- 存档和设置留在本地，交付时说明位置和安全重置方式；不读取其他个人文件，不收集遥测。理由：Brief §9。

## Plan

- 检查点：战前准备的每次改动、待选奖励和整轮结束时写入。战斗进行中不保存中间状态，中途离开后回到该场战前准备并提示。
- 存储：本机服务把 JSON 原子写入用户数据目录（macOS `~/Library/Application Support/EchoArena/`，Windows `%APPDATA%\EchoArena\`），并保留上一版备份；没有本机服务时改用浏览器 localStorage。
- 窗口失焦或页面隐藏时自动暂停并挂起音频，可在设置中关闭。
- 新开一轮会覆盖当前进度时二次确认；设置中提供“清除全部存档”。

## Acceptance criteria

- 关闭页面或停止服务后重新进入，能回到正确的场次与配置，并有说明。
- 设置修改在重启后保留；重置操作有确认，重置后的状态干净。
